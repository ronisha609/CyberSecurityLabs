# Threat Hunt & Detection — T1562.001

By Ronisha Showers · Independent portfolio project


## Project Overview
This project converts threat intelligence into a structured hunt and detection rule for MITRE ATT&CK T1562.001, focusing on EDR network silencing and attempts to weaken Microsoft Defender.
## Assessment Focus
- Threat-hunt hypothesis and ATT&CK mapping
- Required endpoint and security telemetry
- Hunt queries and detection logic
- Testing and validation approach
- False positives and tuning considerations
- Escalation criteria and analyst response
## Skills Demonstrated
**Threat hunting, detection engineering, MITRE ATT&CK analysis, telemetry selection, false-positive analysis, validation, and incident escalation.**
